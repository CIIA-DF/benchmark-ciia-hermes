# Decisões

[ADR 001 — base inicial](001-base-inicial.md) registra escolhas implementadas e alternativas adiadas. [ADR 002 — atualização manual das equipes](002-atualizacao-manual-equipes.md) substitui a decisão sobre propagação da main em 30/09/2026. [ADR 003 — provedor de inferência OpenRouter e benchmark em duas camadas](003-provedor-inferencia-openrouter.md) define o gateway OpenRouter, a divisão metodológica em Camada 1 e Camada 2 e o controle do teto orçamentário de $25 USD. Novas decisões devem registrar contexto, escolha, consequências, responsáveis e situação (proposta/aprovada/substituída). Não altere retrospectivamente uma decisão para esconder mudança experimental.
