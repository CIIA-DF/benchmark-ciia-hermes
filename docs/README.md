# Bem-vindo ao Projeto CIIA-DF (Benchmark SEI)

Bem-vindo(a) à equipe! Este portal é o ponto de partida para os bolsistas do CIIA e NIAUnDF. Aqui você encontra as diretrizes, configurações e a documentação para contribuir com o projeto de orquestração do SEI.

Siga os **4 passos abaixo** para configurar seu ambiente e iniciar suas atividades com sucesso.

---

### Passo 1: Entenda o projeto
Antes de programar, entenda os conceitos base, as ferramentas e o glossário.
**[Ler Glossário e Visão Geral](00-comece-aqui/03-glossario.md)**

### Passo 2: Configure o ambiente e rode a demo
Configure o Python (uv), instale as dependências e faça a demo rodar no seu computador. Esta é a prova de que tudo funciona!
**[Ler Guia de Início Rápido (Demo)](00-comece-aqui/01-inicio-rapido.md)**

### Passo 3: Aprenda o fluxo Git
Toda contribuição passa por revisão. Aprenda como sincronizar seu código, evitar conflitos e aprovar PRs seguindo as nossas regras.
**[Ler Fluxo Git Obrigatório](00-comece-aqui/02-fluxo-git.md)**

### Passo 4: Conheça sua equipe
Saiba o que a sua equipe faz, quem são os integrantes e qual é o seu primeiro objetivo.
**[Conhecer as Equipes](00-comece-aqui/04-equipes.md)**

---

## Estrutura de Documentação
Se já terminou os passos acima, você pode navegar pelos outros recursos do projeto no menu lateral:
- **01. Visão Geral**: Backlog e status das tarefas.
- **02. Arquitetura**: Desenho técnico, componentes e integração de LLMs.
- **03. Equipes**: Guias específicos para cada frente técnica.
- **04. Operações**: Deploy, infraestrutura e devops.
- **05. Decisões**: ADRs (Architecture Decision Records).
- **06. Arquivo**: Propostas antigas e documentação histórica preservada.
