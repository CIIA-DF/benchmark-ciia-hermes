# Decisões

[ADR 001 — base inicial](001-base-inicial.md) registra escolhas implementadas e alternativas adiadas. [ADR 002 — atualização manual das equipes](002-atualizacao-manual-equipes.md) substitui a decisão sobre propagação da main em 30/09/2026. Novas decisões devem registrar contexto, escolha, consequências, responsáveis e situação (proposta/aprovada/substituída). Não altere retrospectivamente uma decisão para esconder mudança experimental.
